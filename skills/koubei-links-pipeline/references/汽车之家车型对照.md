## 使用说明

1. **series ID 优先从本表读取。** 表格里的车型名会做归一化（去掉空格/连字符）后再比对。
2. **留空时脚本走搜索兜底**（`sou.autohome.com.cn`），搜到什么不保证准——**搜完必须 Read 生成的官方参考图确认车型没抓错再批量比对**，否则整批判定全废。
3. 确认后的 series ID 会缓存到 `data/autohome_series.json`；建议顺手回填到本表，长期更稳。
4. 也可运行时直接指定：`python fetch_autohome_refs.py --series <ID> refs 12`。

## 怎么找 series ID

打开汽车之家车型主页，URL 里的数字就是：
```
https://www.autohome.com.cn/5050/        →  series ID = 5050
https://car.autohome.com.cn/photo/series/5050/1.html   →  该车型官方外观图页
```
`photo/series/<ID>/1.html` 中末尾 `1` 是「车身外观」分类（`12`=中控方向盘、`13`=车厢座椅）。

## 官方外观色

- **不是 R3 颜色判定的依据**（R3 只比口碑自己的车身漆面色），这列仅供人工参考，可整列留空。
- 想填的话用顿号或逗号分隔都行（脚本按 `[、,，;；]` 切分），抓取时会打印出来提示。
- ⚠️ **R3 颜色不等同于「与官方色是否一致」**：展厅车/同款白底翻拍不算车主原车车身色，**只有口碑内的多张外观图之间车身漆面色不一致** 才是 R3 `颜色不统一`。
