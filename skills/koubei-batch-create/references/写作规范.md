# 口碑批量创作写作规范

## 一、判定标准(用户定稿)

1. **每篇2-3个小点**,数量随机(实践中 42篇2点/18篇3点 的自然分布),**严禁每篇铺满五六个点**——这是与普通改写最核心的区别,追求「真实车主随手写口碑」的状态
2. **字数**:纯汉字 380-450/篇(中位约400)。每个小点 150-200 字,写透:观点+数字+场景+对比
3. **小点组合与顺序随机**:有的篇【外观】开头,有的【最满意】开头;「外观+续航」「最满意+空间」「驾驶感受+智能化+性价比」……组合、顺序全部错开
4. **人设**:每车型10篇人设互不相同,跨车型尽量错开;开头一句人设/购车背景引入(无标题)

## 二、写作格式模板

```
## 3-宝妈接送专用(398字)

两个娃,老大上小学老二幼儿园,以前骑电瓶车接送,换了缤果S 325km款,落地六万八。

【空间】四米二的车,后排装两个安全座椅后,中间还能挤下我妈……(150-200字)

【驾驶感受】这车最好开的是平顺……(150-200字)
```

要点:
- 小点标题用【】,内容紧接小点主题,无需空行内另起小标题
- 结尾自然收(可并入最后一个小点,或一句小结「值」「够用」),不套「适合谁/不适合谁」模板
- 开头句式与结尾句式在60篇中都要错开,防模板感

## 三、每条铁律(承接总提示词,优先级最高)

1. 基于真实体验,每个观点必须挂论据(数字/场景/细节),禁「空间大、续航好、性价比高」空话
2. 客观平衡:优点再亮眼也要有适用条件或小缺点;吐槽就事论事给改进期待
3. 期望值校准:全篇至少一处「这个价位就不追求XX了」式表达(2-3点版中至少1点内体现)
4. 克制带货腔:拉满/闭眼入/吊打/真香等词全篇最多1处,优先用生活化表达(家用够了/老婆也能开/一周一充)
5. 保留事实底线:数字不编造、不夸大;车主主观评价保留;燃油版油耗、插混纯电+综合+亏电油耗要写准确

## 四、人设池(可混搭,每车型10个)

通勤上班族 / 跨城通勤 / 宝妈 / 奶爸 / 二胎·三胎·多孩家庭 / 应届生 / 大学生 / 退休夫妻 / 退休阿姨 / 网约车司机 / 顺风车 / 早餐店主 / 水果店主 / 建材业务员 / 教师 / 乡村教师 / 护士 / 夜班打工人 / 露营玩家 / 钓鱼佬 / 摄影师 / 程序员 / 民宿老板 / 果园主 / 驾校教练 / 返乡青年 / 小老板 / 公司行政 / 包车司机 / 油转电老司机 / 老司机评车 / 家庭首购 / 多车家庭 / 抢车位上班族 / 女孩第一台车

## 五、过审要点(懂车帝/汽车之家风格)

- 开头要有「人」:购车背景/换车动机/预算/对比车型,素材没有就用1-2句画像,不编造细节
- 有价格明细的单列:指导价/优惠/落地/保险,数字全保留——价格透明是真实帖最强信号
- 夸要挂在场景上,鼓励优点夹一个小缺点
- **驾驶体验必须专业量化**(2026-09-12 客户反馈新增):「懂车分/正文描述模糊、建议增加专业驾驶体验」是高频返工意见。禁止只写「开起来挺顺手/坐着挺舒服/底盘很稳」这类无依据形容词,每个主观感受后面必须挂一个可量化指标——
  - 动力:综合功率 kW/Ps、扭矩 N·m、零百加速 s、电驱「踩多少给多少」有无迟滞
  - 底盘悬架:悬架形式(双叉臂/多连杆)、是否液压车身、主动预瞄、行程调节 mm、最高离地 mm、过减速带余弹表现
  - 转向/操控:最小转弯半径 m、低速轻高速重、回正手感、车身宽度带来的会车难度
  - 补能:平台电压(800V)、10-70%/10-97% 分钟数、10 分钟补能里程
  - 成本/安全:亏电油耗 L、综合续航 km、气囊数、爆胎稳停车速
- **裸车价与落地价分开写**:「优惠 3 万」是裸车口径,写成落地会失真。统一「指导价 X → 优惠+置换 Y → 裸车 Z → 落地 W」链路
- 数字口语化:谷电6毛一度、一公里8分钱、一周一充、一箱油52升跑650公里

## 六、常见返工原因与对策

| 返工原因 | 对策 |
|---|---|
| 每篇小点太多(5-7个) | 强制2-3个,一个点写150-200字 |
| 字数不足(纯汉字<370) | 每个小点内补数字/场景/对比,或用 append_pieces.py 补写 |
| 事实硬伤(价格/续航错) | 一律走 references/车型事实库.md,新车型先 WebSearch |
| 模板感(开头结尾句式重复) | 人设差异化+句式错开,60篇内抽查前10篇 |
| 同篇重复小点标题 | check_koubei.py 专门检查 |
| 懂车分内容描述模糊(空泛形容词) | 每个主观形容词后挂可量化指标(动力 kW/零百、底盘 悬架形式/行程/离地、转向 转弯半径、补能 分钟数),见第五节 |
| 价格口径失真(裸车写成落地) | 统一「指导价→优惠+置换→裸车→落地」,落地要含保险与购置税 |
| 跨篇重复(8-10字片段撞车) | 写完必跑 `scripts/dedup_check.py <口碑目录>`,不达标就按片段原文换措辞复检,见第八节 |

## 七、汽车之家「满级精华」长文口径(单篇 800-1000 纯汉字)

汽车之家满级精华口碑的字数门槛比懂车帝高,单篇按 **800-1000 纯汉字**写,**9 个小点全用**,顺序固定:

```
【最满意】【不满意】【空间】【驾驶感受】【续航】【外观】【内饰】【性价比】【智能化】
```

- 开头一段「购车背景」(无标题):地域+职业+家庭+前车+预算+对比车型+提车时间+里程
- 结尾一句收束(不落「适合谁不适合谁」模板)
- 优点集中在【最满意】【空间】【驾驶感受】【续航】【智能化】;缺点写进【不满意】并在【外观】【内饰】展开
- 长文尤其要防「摊薄」:每个小点必须有一个以上可核查数字,不能靠形容词凑长度

## 八、2026 年价格与购置税口径(必须遵守)

- **2026-01-01 起新能源车购置税减半征收**(2024-25 免征,2026-27 减半,每辆减税上限 1.5 万元)
- 算法:计税价 = 指导价 ÷ 1.13,应缴 = 计税价 × 5%
  - 19.98 万的车 → 19.98 ÷ 1.13 × 5% ≈ **0.88 万(八千八)**
- 落地价 = 指导价 + 购置税 + 保险(0.7 万上下) + 上牌 − 置换补贴/贴息
  - 19.98 万级纯电:落地合理区间 **21.0~21.3 万**
- **写 2026 年新能源口碑不带这一笔,落地价算不圆,会被懂行的人一眼看穿**
- 同车型多篇的落地价允许小幅浮动(保险/贴息差异),但必须落在同一自洽区间

## 九、跨篇去重执行流程(实测把 10/15 篇对重复降到 0/15)

1. 写完全部篇目
2. 跑 `python scripts/dedup_check.py <口碑目录>`(默认 10 字级)
3. 有重叠 → 按报告给出的片段原文回到那两篇,把该处换成同事实的另一种说法,**不要删信息**
4. 复检到 0 再交付

高频雷同只有三类,盯住这三类就够:

| 雷同类型 | 例子 | 换措辞示例 |
|---|---|---|
| 小点开头套话 | 「最满意是补能。」「内饰挑两个具体的。一是…二是…」「要说不满意,还是外观和内饰」 | 「最让我服气的是补能速度。」「说两个我实际用出来的问题。」「外观和内饰这两项,是我打分最低的地方。」 |
| 数字套话 | 「减半的购置税交了八千八,落地二十一万一出头」 | 「税减半,购置税八千八,保险七千多,加起来二十一万出头开走」/「购置税减半后交了八千八,全办完二十一万二」 |
| 提车句 | 「…定了这台675后驱闪充版,19.98万,到现在跑了…」 | 「7月底把车开回来的」/「5月底入手」/「6月初在佛山买的」 |

同事实的措辞库:
- 车宽:「车宽1995mm」/「车身一米九九宽」/「一米九九的车宽」
- 续航:「CLTC标675公里」/「标称675公里」/「官方675公里」/「表上写着675公里」/「标的675公里」
- 造型:「方盒子加封闭前脸」/「方方正正的封闭前脸」/「四方的前脸」/「方正的车身配封闭前脸」
- 高阶智驾:「天神之眼B我没选装」/「加钱的那套高阶智驾我没要」/「带激光那个版本得加钱」

## 十、字数估算红线(反复踩)

**手写字数的估算会系统性偏低 20-25%**——凭感觉估 900 字,脚本实测常有 1100+。批量写完后必须先 script 计数再交付,不要凭手感判断。
